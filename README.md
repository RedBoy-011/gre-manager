# GRE Tunnel Manager v2.0 🚀

نسخه دوم و کاملاً بازنویسی شده از اسکریپت مدیریت تانل لایه ۳ (GRE). این نسخه با الهام از معماری شبکه‌های تجاری طراحی شده و از سیستم جفت‌سازی بر پایه توکن (Token-based Pairing) بهره می‌برد.

پروژه‌ای از **فزار فناور | فناوران زیرساخت داده راهورد**

## ✨ ویژگی‌های کلیدی (نسخه ۲.۰)

*   **کارت شبکه داینامیک (Dynamic Interfaces):** اسکریپت به صورت هوشمند اینترفیس‌های آزاد (gre1, gre2, ...) را پیدا کرده و تانل جدید را روی آن‌ها می‌سازد. **هیچ تداخلی با سایر پنل‌ها و کانفیگ‌های روی سرور شما نخواهد داشت!**
*   **جفت‌سازی با توکن (Token Pairing):** نیازی به وارد کردن دستی آی‌پی‌ها در هر دو سرور نیست. سرور اول یک رشته رمزنگاری شده (Base64) به شما می‌دهد؛ آن را در سرور دوم پیست کنید تا تنظیمات شبکه‌های خصوصی، زیرشبکه‌ها و آی‌پی‌ها کاملاً اتوماتیک انجام شود.
*   **فورواردینگ پورت انتخابی (Selective NAT):** برخلاف نسخه‌های قبلی که کل ترافیک سرور را با `MASQUERADE` منتقل می‌کردند، در این نسخه می‌توانید دقیقاً مشخص کنید که *فقط پورت‌های خاصی* (مثلاً 51820 برای وایرگارد) وارد تانل شوند.
*   **ساب‌نت رندوم:** برای جلوگیری از تداخل آی‌پی‌های لوکال (Local IP Conflict)، اسکریپت در هر بار ساخت تانل، یک رنج شبکه خصوصی کاملاً رندوم (مثلاً `10.200.67.x/30`) تولید می‌کند.
