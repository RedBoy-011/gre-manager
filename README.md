# GRE Tunnel Manager 🚀

اسکریپت مدیریت و راه‌اندازی اتوماتیک تانل لایه ۳ (GRE) برای بهینه‌سازی ارتباطات بین سرورهای خارج و ایران. این معماری به صورت اختصاصی برای عبور ترافیک‌های مبتنی بر UDP (مانند **WireGuard**) با کمترین افت پکت و بالاترین پایداری طراحی شده است.

پروژه‌ای از **فزار فناور | فناوران زیرساخت داده راهورد**

## ✨ امکانات اسکریپت

*   **نصب هوشمند پیش‌نیازها:** بررسی خودکار پکیج‌های مورد نیاز (مانند iptables و iproute2) و پرش از مرحله دانلود در صورت نصب بودن (بسیار مناسب برای سرورهای ایران که ممکن است اختلالات دانلود داشته باشند).
*   **پیکربندی اتوماتیک مقادیر:** پیشنهاد مقادیر پیش‌فرض استاندارد برای شبکه‌های خصوصی (مثل 10.255.255.1/30) با قابلیت ویرایش در زمان نصب.
*   **پشتیبانی کامل از IPv4 و IPv6:** اعمال خودکار مقادیر sysctl و مسیریابی کامل آی‌پی‌ها.
*   **تست درون‌برنامه‌ای:** امکان پینگ‌گیری مستقیم درون تونل برای اطمینان از برقراری هندشیک و سلامت ارتباط.
*   **پاکسازی تمیز (Clean Uninstall):** حذف سرویس‌های Systemd، پاک‌سازی اینترفیس‌ها و حذف رول‌های IPtables تنها با یک کلیک.

## 🚀 نصب و اجرا (دستور تک‌خطی)

برای اجرا، کافیست دستور زیر را کپی کرده و با دسترسی روت (root) در ترمینال سرور خود وارد کنید:

```bash
bash <(curl -Ls https://raw.githubusercontent.com/RedBoy-011/gre-manager/main/gre-manager.sh)
```

## ⚙️ معماری پیاده‌سازی شده

این اسکریپت به جای دستکاری مستقیم سیستم، دو سرویس مجزا و استاندارد را در لینوکس ایجاد و مدیریت می‌کند:
1. **tun.service**: مدیریت لینک GRE بین دو سرور و تخصیص آی‌پی‌های تانل.
2. **gre-nat.service**: مدیریت فورواردینگ ترافیک‌های خروجی و اعمال رول MASQUERADE روی اینترفیس اصلی سرور (معمولاً eth0).
